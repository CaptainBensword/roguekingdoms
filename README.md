# Talon Card Game Index — Rogue Kingdoms

A static GitHub Pages site for Talon's **Rogue Kingdoms** tabletop game. The index includes the XP reward-card collection, illustrated card backs, complete starter rules, a recommended hex-map reference, and a browser-only demo draw pile.

## What's in the site

- **16 XP reward cards:** four copies each of 10, 20, 35, and 50 XP.
- **Original supplied card artwork:** the supplied card-sheet image is cropped into four separate card-face assets and one reverse asset in `assets/`.
- **Card index:** XP filters, card-ID search, accessible flip interaction, and responsive card layout.
- **Rogue Kingdoms rules:** 2–4 player pirate-themed territory and monster game using swordsmen, archers, trolls, lookouts, monster lairs, and the XP reward deck.
- **Deck demo:** draw from a shuffled practice deck and reset it without changing the physical-game rules or cards.

## Publish on GitHub Pages

Keep `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets/` folder at the repository root. In GitHub, open **Settings → Pages** and publish from the `main` branch, `/ (root)`.

## Game at a glance

- 2–4 captains; recommended play time 30–45 minutes.
- 19 connected hex spaces, four home ports, four claimable Lookouts, and three monster lairs.
- Each captain takes two orders per turn: March, Muster, Challenge, or Claim.
- Defeat monsters and claim Lookouts to draw XP cards.
- First captain to 100 XP wins. If the deck runs out, finish the round and compare XP.

The rules on the website are the standard starter rules for this first edition and can be expanded as the physical board and pieces are finalized.
